# Passenger-facing Fiido T2 pogie

Open index.html directly in a browser. No server or dependencies. The hood opens inward along the entire rail-facing edge; its soft roof must lift freely for upward withdrawal. The manufacturer photo establishes general approach direction, not dimensions. Two captive hook-and-loop straps attach to the rail. All dimensions are provisional. Print A4 at 100% and check the 50 mm bar. Sew a scrap mockup and test stationary before using good fabric. Do not ride with an unvalidated prototype.

Geometry: src/pogie.js. The original geometry module and tests remain as historical baseline, not used by this UI. Shell and lining share a provisional template; lining fit must be adjusted physically. No certification or thermal performance claimed.
